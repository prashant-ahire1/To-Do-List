# To-Do List Web Application 

<p>A simple and responsive To-Do List Web Application built using HTML, CSS, and JavaScript.
This project helps users manage daily tasks by adding, completing, and deleting tasks easily.</p>

<h4>Features</h4>
<li>Add new tasks</li>
<li>Mark tasks as completed</li>
<li>Delete tasks</li>
<li>Responsive user interface</li>
<li>Simple and clean design</li>
<li>Real-time task management</li>

<h4>Technologies Used</h4>
<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript (Vanilla JS)</li>


<h4>Learning Outcomes</h4>

<p>Through this project, I learned:</p>

<li>DOM Manipulation</li>
<li>Event Handling in JavaScript</li>
<li>Responsive UI Design</li>
<li>Basic Frontend Development</li>
<li>CRUD operations using JavaScript</li>
